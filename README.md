# Shadows-of-Cities-website

Веб-сайт для проработки CRUD-операций (в виде каталога карточек заброшенных мест). Учебный проект в рамках практики.

## Функциональность
- Просмотр списка мест на главной странице
- Детальная страница с описанием каждого места
- Галерея изображений (Swiper.js) на детальной странице
- Админ-панель по адресу `/Admin`:
  - Добавление новых записей с загрузкой фото
  - Редактирование существующих (включая замену изображений)
  - Удаление записей
- Управление категориями через модальное окно в админке
- Динамическая подгрузка городов в зависимости от выбранной страны
- Автоматическое заполнение базы тестовыми данными при первом запуске

## Технологии
- **Бэкенд:** ASP.NET Core (MVC), Entity Framework Core
- **База данных:** SQL Server
- **Фронтенд:** HTML, CSS, JavaScript
- **Библиотеки:** Swiper.js (галерея изображений)
- **Контейнеризация:** Docker, Docker Compose
- **Валидация:** JavaScript + серверная проверка

## Как запустить

### Требования
- .NET SDK 8.0 или выше
- SQL Server (локально) или Docker
- Любая IDE (Visual Studio, VS Code, Rider)

### Локальный запуск (Windows + SQL Server)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ваш-логин/Shadows-of-Cities-website.git
   cd Shadows-of-Cities-website
   ```

2. Настройте строку подключения в `appsettings.json` под ваш SQL Server.

3. Примените миграции и запустите:
   ```bash
   cd WebsiteProgect
   dotnet ef database update
   dotnet run
   ```

4. Откройте браузер и перейдите по адресу:
   ```
   https://localhost:7274/Places
   ```

### Запуск через Docker

1. Убедитесь, что Docker установлен и запущен.

2. Из корня проекта выполните:
   ```bash
   docker compose up -d
   ```

3. Откройте браузер и перейдите по адресу:
   ```
   http://localhost:8080/Places
   ```

4. Чтобы остановить:
   ```bash
   docker compose down
   ```

### Примечания
- При первом запуске база данных автоматически заполняется тестовыми данными (10 мест, справочники стран, городов и категорий).
- Для загруженных фото используется папка `wwwroot/uploads/`.

### Админ-панель
Для управления записями перейдите по адресу `/Admin`. Авторизация не требуется. Доступ открыт для упрощения учебного проекта.

## Структура проекта
- `/Controllers` — контроллеры (публичный каталог и админка)
- `/Models` — модели данных (Place, City, Country, Category, Image)
- `/DTO` — объекты передачи данных
- `/Data` — контекст базы данных и сидер тестовых данных
- `/Migrations` — миграции Entity Framework Core
- `/Views` — HTML-шаблоны (Razor)
- `/wwwroot` — статические файлы (CSS, JS, Swiper)
- `/Dockerfile` — инструкция сборки Docker-образа
- `/docker-compose.yml` — конфигурация Docker-сервисов
