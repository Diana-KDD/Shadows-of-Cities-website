# Shadows-of-Cities-website
Веб-сайт для проработки CRUD-операций (в виде каталога карточек заброшенных мест). Учебный проект в рамках практики.

## Функциональность
- Просмотр списка мест на главной странице
- Детальная страница с описанием каждого места
- Админ-панель по адресу `/Admin`:
  - Добавление новых записей
  - Редактирование существующих
  - Удаление записей

## Технологии
- ASP.NET Core (MVC)
- Entity Framework Core
- SQLite
- HTML, CSS, JavaScript

## Как запустить

### Требования
- .NET SDK 8.0 или выше
- Любая IDE (Visual Studio, VS Code, Rider)

### Установка и запуск

### Админ-панель
Для управления записями перейдите по адресу `/Admin`.
Авторизация не требуется.

## Структура проекта
- `/Controllers` — контроллеры
- `/Models` — модели данных
- `/Data` — контекст базы данных
- `/wwwroot` — статические файлы (CSS, JS)
- `/Views` — HTML-шаблоны
